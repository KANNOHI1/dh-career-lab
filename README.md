# 歯科衛生士キャリアラボ

歯科衛生士がこれまでの経験を事実として並べ直すための、単一 HTML の診断ツール。

- サイト: https://kannohi1.github.io/dh-career-lab/
- 回答はブラウザ内で完結する。サーバーへ送信しない。続きから再開できるよう端末内には保存し、
  いつでも消せる
- 検索避け（noindex）。ビルド・サーバー不要

## 構成

```
index.html   画面（導入ページ + アンケート + 結果）
app.js       導入ページの制御、設問定義、結果の組み立て、端末内保存
data/        統計データ（画面はここから導出するだけ）
  market.js         就業者数・年齢構成などの母数
  certifications.js 認定資格の体系と保有者数
  salary.js         年収データ
  tracks.js         キャリアの選択肢（要件・年収・実態・最初の一歩）
```

## 原則

- 出典 URL のない数値は書かない。未調査は `null` + `// TODO:` のまま残す
- 推定で埋めない。複数の調査で数値が割れたものは `data/` に入れず、`research/sources.md` に
  食い違いとして記録する
- 公表データが揃った選択肢だけを画面に出す（`confirmed: true`）。揃っていないものは
  「調べています」と書かずに出さない。読む人にとって、こちらの進捗は情報ではない
